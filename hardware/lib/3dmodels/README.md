# Synth 3D models

STEP models for parts in the `Synth` footprint library that KiCad's own
libraries don't cover (panel pots, selectors, jacks, the Teensy). In a
footprint's 3D settings, point at them as

    ${KIPRJMOD}/../lib/3dmodels/<file>.step

so the path works on any computer the repo is cloned to.
